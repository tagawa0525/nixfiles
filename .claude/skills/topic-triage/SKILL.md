# Topic Triage

作業中に見つかった問題（$ARGUMENTS）を振り分ける。1つのブランチは1つのトピックで閉じる。

## 現在の状態

!`git branch --show-current`
!`git log --oneline main..HEAD`
!`git worktree list`

## トピックとは

1つの目的（1つの ADR、計画の1項目、1つの issue が目指す結果）。マージのメッセージの Why を1文で言えるもの。

## 振り分け

| 分類                                 | 例                                                                                          | どうするか                                                                                                    |
| ------------------------------------ | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 同じトピック                         | 今の変更で入れた不具合、テストの不足、今の ADR の細部、今の変更に要る小さな下ごしらえ       | 同じブランチで続ける                                                                                          |
| 別のトピックで、今のトピックを止める | 新しい ADR が要る決定、採用済みの ADR を変える必要、main にもとからある不具合で先に進めない | issue に書き、main から別の worktree で先に片付けてマージする。元のブランチはマージ前の rebase でその上に乗る |
| 別のトピックで、止めない             | 気づいた改善、別の場所の不具合、後で決めればよい形式                                        | issue に書いて後回しにし、今のトピックに戻る                                                                  |

目安:

- 新しい ADR が要る、または採用済みの ADR を変える → 別のトピック
- main にもとからある不具合 → 別のトピック。今のブランチの変更が引き起こしたものは同じトピック
- マージのメッセージの What が2つの話題にまたがる → 分け忘れ
- 迷ったら issue に書いてユーザーに報告する

## issue の書き方

- GitHub のリモートがあれば `gh issue create`、なければ `docs/issues/` の README の書式に従う（番号は最大＋1。マージ前の rebase で重なったら振り直す）
- 問題、完了の条件、見つけた経緯を書く。今のブランチ名を経緯に残す
- `docs/issues/` のファイルは文書だけの変更なので、今のブランチにコミットしてよい

## 止めるものを先に片付ける

1. issue を書く
2. `git branch <branch> main` で main からブランチを作り（`worktree-add.sh` は新しいブランチを今の HEAD から作るので、
   作業中のブランチの未完了のコミットが入らないようにする）、`~/.claude/scripts/worktree-add.sh <branch>` で
   worktree を作って、そこで片付けてマージする
3. 元のブランチを main に rebase して作業に戻る

## 完了

```text
振り分け: [同じトピック | 別（止める） | 別（止めない）]
理由: [目安のどれに当たるか]
記録: [issue の番号か URL | なし]
次: [同じブランチで続ける | worktree <path> で先に片付ける | 今のトピックに戻る]
```
