# ADR-0044: スキルと依頼は、することを肯定形で書き、禁止だけの文を置かない

## 背景

2026-10-20〜21 にサブエージェントへ頼んだ 5 本（PR #402、feat/hook-require-pipefail、#407、#410、#412）は、どれも
レビューの指摘に従って範囲を広げ続け、周が終わらなかった。依頼文は delegate のテンプレート（ADR-0027 の「リポジトリ、
ブランチ名、何をするか、禁止事項」）に沿い、禁止事項の欄には「〜に触れない」「〜を変えない」を並べていた。
何ができれば完成かは書いていなかった。

禁止の文は、してはいけないことの補集合を許すだけで、何をするかを決めない。スキルと CLAUDE.md にも、禁止だけの
文が多い（2026-10-21、08dad24 の `.claude/CLAUDE.md` と `.claude/skills/*/SKILL.md` で、
`grep -cE '禁止|しない|ない[。、）]|使わない|書かない|触れない|変えない|待たない|頼らない|入れない'` を数えて
117 行。delegate 26、gh-pr-review 16、CLAUDE.md 15）。

ユーザーの言葉（2026-10-21）: 「補集合はそれ以外すべてなので実行的ではないと思います」。

## 検討した案

- 案 A: 依頼のテンプレートの欄を、することを書く欄（何をするか、完成の形、変える範囲）にする。スキルと CLAUDE.md の
  禁止の文も、することの文に書き直す
- 案 B: テンプレートに「終わりの条件」（規模の目安、周の数、許す漏れ）の欄を足す（PR #414 の最初の版）。周の数は
  ADR-0027 の「独自の周回数を決めない」と、許す漏れは #411 で捨てた「正しい指摘でも周を止める」規則と食い違う
- 案 C: 禁止事項の欄を残し、書き方の注意を足す
- 案 D: 案 A に加え、範囲の外を変える必要が出たら受けた側が止まる規則を足す（PR #414 の途中の版）。ローカル
  レビューの 3 周で、push、`~/.claude`、topic-triage の振り分け、報告のテンプレートとそれぞれ食い違った

## 決定と理由

採用: 「案 A」。

- 依頼のテンプレートは「何をするか」「完成の形」「変える範囲」で書く。完成の形には、テストや確認で示す振る舞いを、
  変える範囲には、変えてよいファイルを書く。受けた側は完成の形を満たすところまで作り、範囲の外を変えたものは
  報告で分けて書く
- スキルと CLAUDE.md は、することを肯定形で書く。代わりの行動がある禁止は、その行動を先に書く。hook が強制する
  ことは書かない（hook の文言が理由と修正方法を示す）
- 守る理由が局所的な罠（「出力を `tail` につなぐと終了コードが消える」など）は、することの文に理由として添える

案 B は、周の終わりを依頼ごとに変えることになり、既存の決定と食い違う。案 D は、スキルのほかの手順と食い違い続け、
その直しで周が終わらなかった。案 C は、補集合が残るので何をするかが
決まらない。

### 帰結

- ADR-0027 の「依頼に書くもの」は、この ADR の 3 つの欄に置き換わる（ADR-0027 の補足からこの ADR を指す）
- スキルと CLAUDE.md の書き直しは #416 で行う

### 確認

- delegate のテンプレートが 3 つの欄を持ち、受けた側の手順が完成の形まで作り、報告に満たしたかを書く

## 補足

- 2026-10-28: 頼む側の書き方に、「変える範囲」へ issue の作成と追記を含めると書く 1 行を足した。「変える範囲」に変えてよいファイルを書き、
  範囲の外を変えたものを報告で分けて書く決定は変えず、範囲に書くものの細部にあたる。xlc の ADR-0209 の依頼は範囲の issue を
  1 本に限り、担当は `--timed` で測った大きさに釣り合わない時間（xlc f434af311、2026-10-28、Slurm 563 と 565。1 回の自己遮蔽が
  2A の 39 ピンで 74〜77 秒、1C の 1 ピンで 76〜77 秒）を、関係する issue が範囲の外だとして報告にだけ残した。受ける側の手順 4 は
  すでに「止めない別のトピックは issue に書く」と書いているので、受ける側に例外を足す版（範囲に無くても issue を書く）は同じ
  規則の言い直しになる。担当が範囲を理由に見送らないよう、頼む側で範囲に含める形にした
