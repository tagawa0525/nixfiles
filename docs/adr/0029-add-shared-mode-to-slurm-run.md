# ADR-0029: slurm-run.sh に、排他でない投げ方 -c を足し、時間は当てにならない印を付ける

## 背景

`slurm-run.sh` は、ジョブを必ず `--exclusive` で投げる（ADR-0007）。排他にするのは、計算資源の奪い合いと、時間を記録する
測定の乱れを防ぐためである（ADR-0026）。

時間を記録しない計算にも、長いものがある。xlc の何時間もの OpenMC の参照解や、開発中の試行である。これらは全コアを
占めなくてよく（OpenMC のスレッド数は入力で決まる）、記録に書く時間も要らない。排他でしか投げられないと、1 本ごとに
ノード全体を占め、ほかの計算を待たせる。

## 検討した案

- 案 A（採用）: `-c <コア数>` を足す。`--exclusive` を付けず `--cpus-per-task=<コア数>` を渡す。ログの末尾の TIME 行と
  ジョブの連絡先（`squeue` の `%k`）に、排他でない印を付ける
- 案 B: 排他かどうかを選ぶ `--shared` と、コア数の `-c` を別のオプションにする。コア数だけを書いて排他のままにする
  間違いは防げるが、オプションが 2 つになる。コア数を渡すことが排他でない投げ方を意味する 1 つの形で足りる
- 案 C: `sbatch` を直接使う。名前、ログ、見積もり、連絡先が抜ける（ADR-0007）

## 決定と理由

案 A を採る。コア数を書くことが「資源を決めて投げる」ことなので、1 つのオプションにする。

- `-c <コア数>` は正の整数で、`--cpus-per-task` に渡す。`--exclusive` は付けない。Slurm の `CPUs` はハードウェアスレッドで
  数え、割り当ては `CR_Core` により物理コア単位（2 スレッド）に切り上がる
- 排他でないジョブの時間は、ほかのジョブと CPU とメモリの帯域を取り合うので、記録に書く値としては当てにならない。
  ログの末尾の TIME 行に `shared (-c <コア数>): 時間は当てにならない` を足す。排他のジョブの TIME 行は変えない
- 連絡先（`--comment`）に `shared-cpus=<コア数>` を足す。`squeue` で、排他の短いジョブが始まらない理由が読める

### 帰結

- 排他のジョブは、ノードに走っているジョブが 1 つもないときにしか始まらない（sbatch(1) の `--exclusive`:
  「ほかの走っているジョブとノードを共有しない」。この設定での確認は、下の「確認」の最後の項目）。排他でないジョブが走っている間は、あとから投げた排他のジョブ、とくに時間を記録する測定は始まらず、
  その終わりを待つ。逆に、排他のジョブが走っている間は、排他でないジョブも始まらない。つまり、排他でないジョブは
  排他の短いジョブと重ならない。重なるのは、排他でないジョブどうしだけである
- 使いどころは、排他のジョブが待っていないときに、時間を記録しない長い計算を複数本、または 1 本流すこと。時間を記録する
  測定の予定があるときは、排他でない長いジョブを入れない
- メモリは Slurm が数えない（`CR_Core`、`modules/slurm/common.nix`）ので、排他でないジョブを複数流すと、メモリの合計が
  搭載量を超えて OOM killer が長い計算を殺しうる。投げる側が合計を数える
- jobcomp（`/var/log/slurm/job_completions`）は排他かどうかを持たないので、`slurm-history.sh` の実績に排他でないジョブの
  時間が混ざる。排他でないジョブは名前の末尾に `-shared` を付けて分ける（スキル slurm-run）
- 見積もり（`-t`）が外れて長引いた排他でないジョブは、待っている排他のジョブの始まりの見込みを狂わせる
  （`OverTimeLimit=UNLIMITED`。ADR-0007）

### 確認

- `.claude/tests/scripts/slurm-run.sh` で、`-c` が `--exclusive` なしで `--cpus-per-task` を渡すこと、TIME 行と連絡先に
  印が付くこと、排他のジョブには付かないこと、コア数が正の整数でなければ投げずにエラーになることを確かめる
- 未確認: 反映後に、待ち行列が空のときに、`-c 1` のジョブを流している間、排他のジョブが `PENDING` のままであることを
  `squeue` で確かめる。確かめたら `status: accepted` にする
